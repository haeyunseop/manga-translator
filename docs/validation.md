## 실제 한 페이지 결과

scripts/validate_real.py로 자체 제작한 일본어 그림을 실제 OCR하고 실제 모델로 번역한 뒤 복원·식자했다.

| 실제 OCR | 신뢰도 | 실제 NLLB 출력 |
|---|---|---|
| こんにちは。 | 93.2% | 안녕하세요 |
| ありがとう。 | 93.8% | 고마워요 |

첫 로딩을 포함한 해당 실행은 **8.37초**였다. 다른 PC에서 같은 속도를 보장하는 수치는 아니다. artifacts/demo-translated.png의 두 말풍선과 원문 제거 결과를 눈으로 확인했다. 결과는 미리 정해 둔 번역 문자열이나 테스트 stub을 주입한 것이 아니다.

공식 기본 모델: facebook/nllb-200-distilled-600M, revision f8d333a098d19b4fd9a8b18f94170487ad3f821d. 가중치는 CC-BY-NC-4.0이며 개인·비상업 사용 대상이다. 다운로드 시 공식 LFS SHA-256과 대조했고 모델 폴더의 provenance.json에 기록했다. 이후 추론은 local_files_only=True다.

처음 검토한 M2M100 418M은 실제 추론에서 인사말을 반복하고 짧은 감사 표현을 부자연스럽게 번역했다. 미리 만든 결과로 덮지 않고 NLLB로 기본 모델을 바꿔 재검증했다. M2M100은 선택 가능한 저품질 대안으로만 남겼다.

## 다중 페이지와 브라우저

실제 API에 자체 제작 페이지 2장을 multipart 업로드했다. 실제 OCR/모델/식자를 거쳐 두 페이지 모두 ready 상태가 되었고, 반환 이미지의 형식·크기 및 인증 제한을 검사했다. 모바일 브라우저에서도 이미지 2장이 로드되고 전체 원본/한국어 전환이 동작하는 것을 검사했다.

test_queue.py는 별도로 명시적인 테스트 stub을 사용해 첫 페이지가 두 번째 페이지 완료 전에 공개되는 시점과 매니페스트 순서를 제어한다. 이 테스트 자체를 번역 품질의 증거로 삼지 않는다. 위 실제 모델 검사와 모바일 검사는 제품 번역기를 그대로 사용한다.

## 네트워크 해결

초기에는 모델 CDN이 Domain forbidden으로 차단됐다. 최신 환경 게시 후 us.aws.cdn.hf.co가 HTTP 200으로 응답했고 실제 모델 다운로드·해시 검증·전체 설치가 성공했다. 현재 네트워크 차단은 해결된 상태다. 과거 진단은 [network-blocker.md](network-blocker.md)에 해결 표시와 함께 보존했다.

## 실사용 한계

검증한 그림은 자체 제작한 선명한 가로쓰기·흰 말풍선 페이지다. 손글씨, 효과음, 루비, 복잡한 배경, 세로쓰기의 일반적인 품질이나 모든 만화 페이지의 완전한 인식은 보장하지 않는다. PC를 끈 채 휴대폰 자체에서 추론하는 기능, 일반 상용 만화 사이트 스크래핑, 공식 ChatGPT OAuth 연결은 구현하지 않았다. Windows 실기·원격 접속·사용할 실제 원본 사이트는 별도 확인이 필요하다.

## Windows 한글 설정 인코딩 회귀 수정

이전 Windows 초기화 도우미가 CP949로 쓴 한글 비밀번호 설정을 UTF-8로 읽다가 실패하는 사례를 재현했다. 초기화 도우미는 새 파일을 UTF-8로 저장하고 기존 CP949 파일은 값·파일 자체·접근 권한을 유지하며 변환한다. 모르는 인코딩은 변경하지 않는다. 설정 관련 회귀 및 API 검사 12개가 통과했다. 이 수정 후 전체 실모델/브라우저 검사를 다시 실행했다고 주장하지 않는다. Windows 자체 실행 검증은 여전히 사용자 PC에서 필요하다.

## Windows OCR 경로 따옴표 수정

pytesseract 0.3.13은 Windows에서 설정을 `shlex.split(..., posix=False)`로 나누므로 따옴표로 감싼 `--tessdata-dir` 값에 따옴표가 남는다. OCR 데이터 경로를 자식 프로세스가 상속하는 `TESSDATA_PREFIX`로 전달하도록 수정했다. 공백·한글이 포함된 임시 폴더에 실제 일본어 데이터를 복사해 자체 제작 그림의 OCR을 검증했으며, 기존의 잘못된 환경 변수도 올바른 경로로 대체되는 것을 확인했다. `backend/tests/test_pipeline.py` **6개 통과**, 건너뛴 검사 없음: 실제 NLLB 한 페이지 번역과 두 페이지 업로드 검사도 포함한다. 이 검사는 Linux에서 실행했으며 Windows 실기 검증은 별도로 필요하다.

## 작은 영역의 식자 중단 수정

고정 10px 여백과 최소 12px 글꼴 때문에 작은 OCR 영역에서 페이지 전체가 실패할 수 있었다. 영역에 비례한 2~10px 여백과 최소 8px 글꼴을 사용하고, 줄 수뿐 아니라 각 줄 폭도 검사한다. 그래도 들어가지 않으면 해당 영역을 갈색으로 표시하고 페이지 아래 번호 순서의 번역 전문으로 제공한다. 모든 번역이 말풍선 안에 들어간 것으로 표시하거나 내용을 잘라내지 않는다. 비정상적으로 긴 번역과 과도한 출력 크기 제한은 유지한다.

`backend/tests/test_pipeline.py` **8개 통과, 건너뜀 없음**. 좁은 말풍선 내부의 실제 한글 렌더링과 경계 밖 픽셀 보존, 번호가 붙은 하단 번역의 전문 보존, 기존 실제 OCR/NLLB/두 페이지 업로드를 검사했다. 사용자가 첨부한 복잡한 세로쓰기 페이지 자체의 전체 OCR·번역 결과와 Windows 실행은 이번 검사로 확인한 것이 아니다.

## 반복 번역·윤곽 밖 식자 수정

앞선 작은 영역 수정만으로 실제 사용 품질이 확보된 것은 아니었다. 사용자가 보고한 결과에는 번역 반복, 의미 왜곡, 너무 큰 글꼴, 말풍선 밖으로 넘친 글자가 있었다. 이전의 최소 8px 축소 방식은 이번 수정에서 대체했다.

- 작은 OCR 영역은 2배 확대해 인식하고 좌표를 원본 크기로 되돌린다. 자동 방향 선택에는 텍스트 영역의 종횡비도 반영한다.
- 말풍선 윤곽을 인식 결과에 보존한다. 원문 제거 마스크와 식자는 윤곽 밖으로 나가지 않도록 제한한다. 식자는 남은 그림 선을 피하고, 글꼴 크기를 페이지 너비에 비례해 제한하며, 단어 사이 줄바꿈을 우선한다. 실제 렌더링한 글자의 알파 마스크가 허용 영역을 벗어나면 그 배치를 사용하지 않는다.
- 모델 생성에 반복 억제를 적용하고, 출력의 반복·과도한 길이·한국어 여부·종료 토큰을 검사한다. OCR 신뢰도 55% 미만 또는 검출된 번역 실패 영역은 일본어 원문을 보존하고 뷰어에 확인 필요 경고를 표시한다. 의미·문맥의 모든 오역을 검출하는 기능은 아니다.
- 들어가지 않는 문장은 페이지 아래에 전문을 유지한다. 이런 경우도 확인 필요로 표시한다. Windows 업데이트 도우미는 기존 모델·설정·사용자 페이지를 유지하고 웹 화면을 다시 빌드한다. 포트 충돌 시 기존 프로세스를 임의 종료하지 않고 명확히 중단한다.

현재 실행: **백엔드 59개 통과, 건너뜀 없음**, TypeScript 검사 및 Next.js 프로덕션 빌드 통과, **모바일 Chromium 4개 통과**. 브라우저 검사 중 3개는 실제 앱/API를 사용하며 그중 데모·다중 페이지 검사는 실제 모델로 실행했다. 나머지 1개는 명시적으로 모의 API 응답을 사용해 확인 필요 경고와 원문 표시만 검증한다. 원문 보존과 낮은 OCR 신뢰도 분기 검사는 테스트용 번역기로 동작 제어를 검증한다.

`scripts/validate_quality.py`는 자체 제작한 세로쓰기·후리가나 포함 그림을 실제 OCR/NLLB/복원/식자로 처리했다. 인식된 세 문장은 fixture 원문과 정확히 일치했고, 원본 크기 684×900 안의 세 말풍선에 식자되었다. [원본](images/quality-original.png)과 [당시 NLLB 출력](images/quality-translated-nllb.png)을 비교할 수 있다. 출력 이미지를 직접 확인했다.

| 실제 OCR | 실제 모델 출력 |
|---|---|
| この町にはまだ知らない物語がたくさんある。 | 이 마을에는 아직 모르는 많은 이야기들이 있습니다. |
| 明日は図書館で友達と会います。 | 내일 도서관에서 친구들과 만나게 될 겁니다. |
| 新しい一日をここから始めよう。 | 이제부터 새로운 하루를 시작하겠습니다. |

**이 그림은 사용자가 보고한 실제 만화 페이지가 아니다.** 채팅에 표시된 이미지의 실행용 원본 파일은 현재 작업 공간에 제공되지 않아 추가 첨부를 요청했다. 해당 페이지 자체의 개선 결과, 복잡한 후리가나·효과음의 일반적 인식 품질, 번역 의미의 완전한 정확성, Windows 실기 실행을 검증했다고 주장하지 않는다. Windows 업데이트 도우미도 이 Linux 환경에서는 직접 실행하지 않았다.

## 기본 엔진 교체: MangaOCR / Qwen3 4B

사용자가 원본과 결과를 비교해 제공했다. 말풍선 배치는 이전보다 개선됐으나, 주어·문장 의미가 바뀌고 하단 말풍선은 단어 목록으로 무너지는 결과가 있었다. 단순 글꼴 조절로 해결된 문제가 아니므로 기본 구성 자체를 변경했다.

- **검출:** Tesseract의 영역 후보와 윤곽을 유지한다. 만화 OCR 모델은 선택한 말풍선 전체를 다시 읽는다. 검출 단계에서 사용하는 기존 Tesseract 점수를 만화 OCR의 정확도로 표시하지 않는다.
- **인식:** `kha-white/manga-ocr-base`, revision `aa6573bd10b0d446cbf622e29c3e084914df9741`, Apache-2.0. 공식 리비전의 LFS SHA-256을 검증한다. 문자 ID 디코딩에 MeCab가 필요 없으므로 추가 일본어 사전·컴파일 도구를 설치하지 않는다. 후리가나·문장 끝 글자도 해당 윤곽 안에서 제거한다.
- **번역:** `Qwen/Qwen3-4B-Instruct-2507`의 Unsloth Q4_K_M 양자화본, revision `a06e946bb6b655725eafa393f4a9745d460374c9`, 파일 SHA-256 `3605803b982cb64aead44f6c1b2ae36e3acdb41d8e46c8a94c6533bc4c67e597`, Apache-2.0. 작은 Qwen3 1.7B도 실제 비교했지만 피동 관계를 잘못 번역해 채택하지 않았다.
- **CPU 실행:** 공식 llama.cpp `b11429`를 GitHub 릴리스의 고정 SHA-256과 대조했다. Windows ZIP도 내려받아 체크섬과 `llama-completion.exe` 포함 여부를 확인했다. **Windows에서 실행했다는 뜻은 아니다.** Linux CPU 실행은 실제 추론에 사용했다. 기존 실행 파일과 동일하면 덮어쓰지 않아 반복 설치의 실행 파일 잠금 오류도 피한다.
- **개인정보:** 로컬 프로세스에 앱 비밀번호·세션 키·클라우드 비밀값을 전달하지 않는다. 입력은 비공개 임시 파일로 전달하고 삭제한다. 명령행으로 대사를 전달하지 않는다. 제한된 프로세스별 문맥 캐시는 로컬에 저장하고 프로세스 종료 시 정리한다. 외부 번역 API·인증 재사용·유료 fallback은 없다.
- **업데이트:** 약 3GB의 새 모델을 한 번 준비하고 웹 빌드가 성공한 뒤 두 모델 선택 설정만 바꾼다. 기존 자격증명·폰트·HTTPS 접근 설정·사용자 데이터·기존 모델은 유지한다. 설정 변경 시 파일의 ACL과 실제 자격증명 값 보존을 검사했다.

실행 결과: 백엔드 **65개 통과**. 이 회귀 모음은 테스트에서 명시한 기존 Tesseract/NLLB 설정으로 API·큐·래스터 처리와 보안/설정 보존을 검사하며, 이를 새 모델 품질 64건의 증거로 계산하지 않는다. 별도로 새 기본 MangaOCR/Qwen 구성에서 `scripts/validate_quality.py`를 실제 실행했고, 새 구성의 모바일 Chromium 검사 **4개 통과**(인증·지원 불가 URL, 실제 데모 번역, 실제 두 페이지 업로드·원본 전환·진단 ZIP 저장, 모의 API의 경고 표시)했다. 프로덕션 빌드/TypeScript 검사도 통과했다.

새 구성의 자체 세로쓰기·후리가나 그림 출력:

| 실제 OCR | 실제 Qwen 출력 |
|---|---|
| この町にはまだ知らない物語がたくさんある。 | 이 마을에는 아직 알지 못한 이야기가 많아. |
| 明日は図書館で友達と会います。 | 내일은 도서관에서 친구와 만나요. |
| 新しい一日をここから始めよう。 | 새로운 하루를 여기서 시작해보자. |

[새 구성의 실제 출력](images/quality-translated.png)은 원본과 같은 684×900 크기이며 이미지로 직접 확인했다. 사용자가 제공한 대사 일부를 텍스트로도 넣어 비교했다. 새 모델은 주체·부정 관계를 대체로 보존했지만 피동 표현·어휘 선택이 어색한 사례가 남았다. 텍스트 비교가 사용자 원본 이미지의 전체 OCR/역식 성공을 증명하지 않는다. CPU 추론은 말풍선당 수십 초가 걸렸고 페이지마다 수분이 걸릴 수 있다. RAM 16GB 이상을 권장한다.

**남은 검증:** 보고된 실제 페이지를 실행하려면 채팅에 표시된 이미지와 별개로 원본 파일 및 실제 OCR 문장을 확보해야 한다. 새 `진단 파일 저장`은 해당 작업의 원본·결과와 JSON만 ZIP으로 제공한다. `.env`·비밀번호·로그·모델 캐시는 포함하지 않는 것을 API 검사와 실제 브라우저 다운로드로 검증했다. 사용자에게 그 ZIP을 요청해 같은 입력으로 남은 문제를 재현할 수 있게 했다. 번역 의미의 완전한 정확성이나 Windows 실기 실행을 완료했다고 보고하지 않는다.
