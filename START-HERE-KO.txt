MangaTrans 시작 안내 (Windows)

휴대폰은 화면과 조작을 담당하고, 번역 계산은 Windows PC가 담당합니다.
PC는 켜져 있고 절전 상태가 아니어야 합니다. 만화 결과 파일을 휴대폰에 다운로드할 필요는 없습니다.

현재 개발 상태: Linux에서 실제 OCR → 한국어 번역 → 클리닝 → 한글 식자와
2페이지 업로드와 자체 제작 세로쓰기 사례를 검증했습니다. 백엔드 59개, 모바일 브라우저 4개 검사 통과.
보고된 복잡한 실제 만화 페이지 자체의 개선 결과는 아직 검증하지 못했습니다.
Windows용 도우미는 작성했지만 개발 머신이 Linux라 Windows 실기 검증은 하지 못했습니다.

1. 압축 파일을 받았다면 전체를 압축 해제합니다. 압축 창 안에서 실행하지 마세요.
2. setup-windows.bat를 실행합니다. 처음 한 번 필요한 도구와 무료 AI 모델을 설치합니다.
   Windows의 설치 확인이 나타날 수 있습니다. 최초에 16자 이상 개인 비밀번호를 정합니다.
   모델 다운로드에는 약 2.5GB와 추가 설치 용량이 필요합니다.
3. 설치가 끝나면 start-windows.bat를 실행합니다. 브라우저가 열립니다.
   설정한 비밀번호로 로그인하고 자체 제작 테스트 페이지부터 시도합니다.
4. 휴대폰 접속은 phone-windows.bat를 실행하고 Tailscale의 공식 로그인 절차를 완료합니다.
   휴대폰에도 공식 Tailscale 앱을 설치해 같은 계정으로 로그인합니다.
   PC에 표시된 https://...ts.net 주소를 휴대폰 Chrome에서 엽니다.
   설정 변경 후에는 기존 MangaTrans 창을 종료하고 start-windows.bat를 다시 실행합니다.
5. 읽는 동안 PC의 MangaTrans 창을 열어 두세요. PC를 끄면 사용할 수 없습니다.

이미 설치했다면 업데이트 방법:
1. 실행 중인 MangaTrans 창에서 Ctrl+C로 종료합니다.
2. 최신 ZIP을 압축 해제하고, 안의 파일과 폴더를 기존 설치 폴더에 덮어씁니다.
   기존 설치 폴더를 지우지 마세요. 비밀번호(.env), 모델, 기존 페이지를 유지합니다.
3. 기존 폴더의 update-windows.bat를 실행해 웹 화면을 갱신합니다.
   이 도우미는 비밀번호 설정이나 모델 다운로드를 다시 하지 않습니다.
4. 끝나면 start-windows.bat를 실행하고 사이트를 새로고침합니다.
   기존 실패 결과는 그대로 남으므로 이미지를 새 작업으로 업로드하세요.

현재 번역 모델은 문맥이나 의미를 틀릴 수 있습니다. 반복 출력과 낮은 OCR 신뢰도가
감지된 영역은 원문을 남기고 확인 필요로 표시합니다. 말풍선에 들어가지 않는 번역은
그림을 덮지 않도록 이미지 아래에 번호 순서로 표시할 수 있습니다.

서버·번역 API 고정 요금이 없는 개인 PC 구성입니다. 전기/인터넷/기기 비용은 별도입니다.
Tailscale 무료 개인 요금제는 제공사의 현재 조건을 확인하세요. Funnel/공개 공유는 켜지 마세요.
오류가 나면 창을 닫지 말고 오류 부분만 캡처하세요. 비밀번호나 .env 내용은 보내지 마세요.
상세 정보, 현재 검증 상태, Linux 설치 방법은 README.md와 docs/validation.md에 있습니다.
